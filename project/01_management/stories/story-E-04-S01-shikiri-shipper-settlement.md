## 2. ユーザーストーリー

卸売業者 担当者として、販売のあった出荷者ごとに、確定取引から仕切書をサーバーの計算でプレビューして発行し、印刷または PDF で渡したい。なぜなら、電卓と手書きの手間をなくし、手計算と 1 円も違わない精算額を、見た内容のとおりに確定させたいからだ。

## 3. 背景・目的

- **現状**：事務所が取引台帳から出荷者ごとの取引を電卓で集計し、委託手数料と消費税を計算して、仕切書を手書きしている（PM 確認、2026-11-23）。手間がかかり、計算や転記の誤りが出荷者との精算トラブルにつながる。
- **目的 1**：出荷者（漁業者・漁協）への精算書である仕切書を、システムの取引データ（E-03-S01／E-03-S02 の確定取引）から作成・発行する。差引支払額＝販売金額（税抜）＋消費税 − 委託手数料 − 手数料の消費税 − 控除（運賃・箱代など）。
- **目的 2**：金額はすべてサーバーが**1 つの計算式**で計算する。率は**仕切日**に有効な業務規程パラメータ（E-01-S04）を使い、端数は合計で切り捨てる（R-03）。手計算との差をゼロにする（NFR-005、overview KPI #2）。
- **目的 3**：1 つの取引は 1 つの仕切にしか入らない。プレビューで見た取引と発行時の取引が一致したときだけ発行し、「見たものと違う内容で確定する」ことを防ぐ。

## 4. 対象ユーザー

| ROLE-ID | ロール | 利用場面 | 権限 |
| --- | --- | --- | --- |
| ROLE-002 | 卸売業者 担当者 | 毎日、販売のあった出荷者ごとに、事務所の PC で仕切書を作成・発行し、紙に印刷するか PDF で出荷者に渡す。1 日数件（ロットは約 10） | プレビュー・発行・取消・一覧と詳細の閲覧・印刷／PDF |

## 5. スコープ

**対象内**
- 仕切書の作成：出荷者、期間（自・至。初期値は本日）、仕切日を選び、対象取引（確定済み・未仕切・その出荷者のロット・期間内の取引日）を集計する
- **控除**：行ごとに名称と金額（円の整数）を自由入力（運賃・箱代など。マスタは持たない）
- プレビュー（DB に保存しない下書き）→ 確認ダイアログ → 発行。金額はすべてサーバーの 1 つの計算式で計算し、率は仕切日に有効な業務規程パラメータ（E-01-S04）を使う。発行した仕切書に率を記録する
- プレビュー後に対象取引が変わった場合は発行しない（再プレビューを求める）
- 承認待ちの例外取引は仕切に含めず、件数を警告表示する。後で承認された取引はその後の仕切に入る（E-03-S01 の決定）
- 仕切書の一覧・詳細・印刷・**PDF ダウンロード**
- **仕切書の取消**：理由必須。取消すと対象取引は未仕切に戻り、取引の取消や再発行ができる。訂正は取消＋再発行で行う（R-09）

**対象外**
- 出荷者への支払い（振込）処理・銀行連携・会計連携（提案書で対象外）
- 控除項目のマスタ管理
- 計算方式の構造変更（手数料の計算基準、端数処理方式の変更）：パラメータではなくソフトウェア改修（R-03）
- 出荷者のログイン・Web での仕切書閲覧
- 買受人への請求・売掛金 → E-04-S02

## 6. 主な業務フロー

> 出典：SPEC-PA-106 v0.1.1（PA_SHIKIRI_SETTLEMENT）、SPEC-PA-205（PA_ISSUE_SETTLEMENT_TECH）

**基本フロー（発行）**
1. 卸売業者 担当者が事務所の PC で仕切書作成画面を開き、出荷者、期間（初期値は本日〜本日）、仕切日（初期値は本日。期間の末日〜本日）を選ぶ。必要なら控除を行ごとに入力する。
2. 「プレビュー」を押すと、サーバーが対象取引を集めて計算した下書きを表示する（保存しない）。販売明細、販売金額（税抜）、消費税、委託手数料、手数料の消費税、控除、差引支払額。率が「仮」なら黄色の注意を出す。承認待ちの例外取引があれば「仕切対象外の承認待ち取引が N 件あります」と表示する。
3. 「発行する」を押すと確認ダイアログ（出荷者、差引支払額、件数、「訂正は取消と再発行で行います」）が開く。
4. 確定すると、プレビューで見た取引と同じ集合であることをサーバーが確認してから仕切書を発行する。対象取引に仕切番号がつき、使った率が仕切書に記録される。
5. 仕切書の詳細画面に移り、印刷または PDF ダウンロードで出荷者に渡す。

**基本フロー（取消・再発行）**
1. 仕切書の詳細で「取消」を押し、理由を書いて確定する。仕切書は「取消」になり、対象取引は未仕切に戻る。
2. 必要なら取引を取消・再入力したうえで、新しい仕切書を発行する。

**代替・例外フロー**
- プレビュー後に条件を変更した：発行ボタンを無効にし、再プレビューを求める。
- プレビュー後に対象取引が増減した（取引の記録・取消・他の仕切書の発行）：発行せず M_44 を表示し、再プレビューを求める。
- 対象取引が 0 件：発行できない（M_40）。
- 差引支払額がマイナス（控除が販売額を上回る）：発行できるが、プレビューと確認ダイアログで「出荷者からの返金が必要です」と警告する。
- 期間が不正（自 > 至）、仕切日が期間の末日より前または未来日、仕切日に有効な率がない、控除の金額が不正：エラー（M_24／M_41／M_45）で計算・発行しない。
- 市場管理者が発行・取消を試みる（API の直接呼び出しを含む）：M_02、DB に変更を残さない。
- セッション切れ：M_01 を表示してログイン画面へ戻す。

## 7. データ要件

> 型・桁数・制約は基本設計で確定する。金額はすべて円単位の整数（ADR-006）。

| 項目 | 取得元 | 表示のみ／編集可 | 備考 |
| --- | --- | --- | --- |
| 仕切番号 | システム採番 | 表示のみ | **システム全体で連番**。取消した仕切書も番号を残し、再発行分は新しい番号で、置き換え元の仕切番号を記録する |
| 出荷者 | 出荷者マスタ（E-01-S02） | 作成時に選択 | |
| 期間（自・至） | 本画面で入力 | 作成時に入力 | 初期値は本日〜本日。取引日で絞り込む |
| 仕切日 | 本画面で入力 | 作成時に入力 | 初期値＝本日。期間の末日〜本日。この日に有効な率を使う |
| 販売明細 | 確定取引（E-03-S01／E-03-S02） | 表示のみ | ロット・品目・数量・単価・金額（税抜）。承認待ち・取消・他の仕切済みは含めない |
| 販売金額（税抜）S | サーバーで計算 | 表示のみ | 明細の金額の合計 |
| 消費税 Tg | サーバーで計算 | 表示のみ | ⌊S × 水産物の税率⌋ |
| 委託手数料 F | サーバーで計算 | 表示のみ | ⌊S × 委託手数料率⌋（計算基準は Q-02 で確定） |
| 手数料の消費税 Tf | サーバーで計算 | 表示のみ | ⌊F × 手数料の税率⌋ |
| 控除（名称・金額） | 本画面で入力 | 作成時に入力（任意、複数行） | 円の整数、0 より大きい |
| 差引支払額 | サーバーで計算 | 表示のみ | S ＋ Tg − F − Tf − 控除合計（マイナス可、警告あり） |
| 適用した率 | 業務規程パラメータ（E-01-S04） | 表示のみ | 仕切書に記録し、後でパラメータが変わっても仕切書の数値は変わらない |
| 状態・取消理由・取消者・取消日時 | 取消操作 | 取消時に入力（理由必須） | 発行済み／取消。仕切書は削除しない（R-09） |
| 発行者・発行日時 | システム | 表示のみ | 監査ログにも記録 |

- 仕切書にはインボイス制度の記載事項（登録番号、税率ごとの区分記載）を加えない（PM 決定、2026-11-23）。様式は §10 #2 で顧客の現行仕切書を確認する。
- 出力：仕切書（画面・印刷・PDF）。仕切済みの取引は E-03-S01／E-03-S02 で取消できなくなる（仕切の取消が先）。

## 8. 技術的制約・非機能面の考慮事項

- **対象端末**：事務所の PC ブラウザ。
- **計算は DB の 1 つの関数だけ**：プレビューと発行は同じ計算関数を使い、画面では再計算しない（ADR-002、ADR-006、R-03）。
- **プレビューと発行の一致**：発行時に、プレビューで見た取引 ID の集合と現在の対象取引が一致するか確認し、違えば発行しない。発行と取引への仕切番号付けは 1 つのトランザクションで行い、同じ取引が 2 つの仕切書に入らないことを DB で保証する。
- **NFR-005 計算精度**：円単位の整数で計算し、端数は合計で切り捨てる。手計算との差ゼロを、合意したテストケースと UAT の並行稼働で確認する（overview KPI #2）。
- **印刷・PDF**：A4 縦の印刷用ページ（印刷用 CSS）を用意し、「PDF」ボタンはブラウザの印刷ダイアログを開いて「PDF に保存」で保存する方式とする（サーバーでの PDF 生成は行わない）。日本語フォントが正しく表示されること。
- **NFR-004 セキュリティ**：発行・取消は卸売業者 担当者だけ（画面と DB の両方）。発行・取消は監査ログに残る。
- **NFR-001 性能**：プレビュー・発行は 3 秒程度以内（1 回あたりの取引は数件〜数十件）。
- 仕切書は削除しない（R-09）。日次バックアップの対象（NFR-007）。

## 9. 受入基準

**計算・プレビュー**
- [ ] Given 出荷者 A の本日の確定取引（合計 S＝265,010 円）と控除 23,600 円、仮の率（水産物 8%、手数料 5.5%、手数料の税 10%）、When プレビューする、Then 消費税 21,200、委託手数料 14,575、手数料の消費税 1,457、差引支払額 246,578 円が表示され、DB には何も保存されない。
- [ ] Given 仕切日を率の改定日の前と後で変える、When それぞれプレビューする、Then 仕切日に有効な率で計算される（取引日の率ではない）。
- [ ] Given 期間内に承認待ち・取消・他の仕切済みの取引がある、When プレビューする、Then それらは明細に含まれず、承認待ちがあれば件数の警告が出る。
- [ ] Given 率が「仮」、When プレビューする、Then 黄色の注意が表示される。
- [ ] Given 控除の合計が販売額を上回る、When プレビューする、Then 差引支払額がマイナスで表示され、「出荷者からの返金が必要です」と警告される。

**発行**
- [ ] Given プレビュー済み、When 確認ダイアログで発行する、Then 仕切書が連番で発行され、対象取引に仕切番号がつき、使った率が仕切書に記録され、詳細画面へ移る。
- [ ] Given プレビュー後に条件を変えた、When 画面を見る、Then 発行ボタンは無効で、再プレビューを求める表示が出る。
- [ ] Given プレビュー後に別の担当者が同じ出荷者の取引を記録または取消した、When 発行する、Then 発行されず M_44 が表示される。
- [ ] Given 対象取引が 0 件、When プレビューする、Then 発行できない。
- [ ] Given 期間の自 > 至、仕切日が期間の末日より前または未来日、仕切日に有効な率がない、When 計算・発行する、Then エラーで処理されない。
- [ ] Given 発行済みの仕切書、When 後で業務規程の率が改定される、Then 仕切書の金額は変わらない。

**印刷・取消・権限・監査**
- [ ] Given 仕切書の詳細、When 「印刷」または「PDF」を押す、Then A4 縦の仕切書が日本語フォントで崩れずに印刷・PDF 保存できる。
- [ ] Given 発行済みの仕切書、When 理由を書いて取消す、Then 「取消」になり、対象取引は未仕切に戻って取消や再仕切ができる。仕切書と番号は残る。再発行した仕切書には置き換え元の番号が記録される。
- [ ] Given 仕切済みの取引、When E-03-S01／E-03-S02 で取消そうとする、Then 拒否される（M_32）。
- [ ] Given 市場管理者、When プレビューする、Then 計算結果は見られるが発行ボタンはない。発行・取消の API を直接呼んでも M_02 になる。
- [ ] Given 発行・取消、When 実行する、Then 実行者・日時・内容・理由が監査ログに残る。
