## 2. ユーザーストーリー

市場管理者として、主要品目の日々の取引数量と価格（高値・中値・安値）を集計した取引結果表を作り、掲示・配布用に出力したい。なぜなら、認定卸売市場の共通ルールである取引結果の公表を、手集計なしで毎日確実に行いたいからだ。

## 3. 背景・目的

- **背景**：2020 年改正の卸売市場法のもと、認定を受けた卸売市場は取引結果（主要品目の数量・価格）の公表などの共通ルールを守る必要がある（提案書の論点 05）。現在は手集計している。
- **目的 1**：確定した取引（相対取引・せり）から、品目ごとの日次の取引結果（数量、高値・中値・安値）を自動で集計し、公表用に出力する。
- **目的 2**：月次の取引結果表を出力し、業務規程にもとづく報告の資料にする。
- **注意**：本機能の範囲は**顧客の確認待ち**（function-list：scope pending customer confirmation）。本ストーリーは最小の範囲で仮置きし、顧客回答で見直す（§10 #1）。規模は見積 v2 の 7.2（FE 1・BE 2 人日）。

## 4. 対象ユーザー

| ROLE-ID | ロール | 利用場面 | 権限 |
| --- | --- | --- | --- |
| ROLE-001 | 市場管理者 | 毎日のせり・相対取引の後に、事務所の PC で当日の取引結果表を出力して掲示・配布する。月初に前月の結果表を出力する | 出力・対象品目の設定 |
| ROLE-002 | 卸売業者 担当者 | 利用しない | なし（role-list） |

## 5. スコープ

**対象内**
- **日次の取引結果表**：指定日の確定取引を品目ごとに集計。数量（単位ごと）、高値・中値・安値、取引件数。相対取引とせりの合計（内訳つき）
- **月次の取引結果表**：指定月の品目ごとの数量・金額・平均単価
- 【確認済み】公表の対象とする「主要品目」を品目マスタで指定できる（初期値はすべての品目）（§10 #1）
- 【確認済み】中値は「取引数量が最も多い価格」とする（§10 #2）
- 出力：A4 の印刷用ページ（ブラウザで PDF 保存、仕切書と同じ方式）と CSV（BOM 付き UTF-8、E-05-S01 と同じ）

**対象外**
- インターネット上の公開ページ（Web 公表）：システムは掲示・配布用の帳票と CSV を出すだけ（PM 決定、2026-11-23。必要なら変更要求）
- 行政・開設者への報告書の様式どおりの作成（月次の結果表と CSV を元に手作業で作る）
- 個別の取引・買受人名を含む公表（公表は品目単位の集計だけ）
- グラフ・相場分析

## 6. 主な業務フロー

**基本フロー**
1. 市場管理者が取引結果の画面で日付を選ぶ（初期値は本日）。
2. 品目ごとの数量、高値・中値・安値、件数が表示される。承認待ち・却下・取消の取引は含めない。
3. 「印刷」または「CSV 出力」で掲示・配布用に出力する。
4. 月次は月を選んで同様に出力する。

**代替・例外フロー**
- 指定日・月に確定取引がない：「対象の取引はありません。」と表示し、空の結果表を出力できる。
- 未来の日付・月：選べない。
- 出力後に、その日の取引が取消・承認された：再度出力すると最新の集計になる（出力日時を帳票に印字して区別する）。
- 卸売業者 担当者が画面を開く・API を直接呼ぶ：画面は表示せず、API は M_02 で拒否する。

## 7. データ要件

| 項目 | 取得元 | 表示のみ／編集可 | 備考 |
| --- | --- | --- | --- |
| 対象日・対象月 | 本画面で選択 | 入力のみ | |
| 確定取引 | E-03-S01／E-03-S02 | 表示のみ | 承認待ち・却下・取消は除く |
| 品目・単位・主要品目の指定 | 品目マスタ（E-01-S03） | 表示のみ（指定は §10 #1） | |
| 数量・件数・金額 | サーバーで集計 | 表示のみ | 単位ごとに集計 |
| 高値・中値・安値・平均単価 | サーバーで集計 | 表示のみ | 中値は取引数量が最も多い単価（同数なら高い方） |
| 出力日時・出力者 | システム | 表示のみ | 帳票に印字、監査ログにも記録 |

## 8. 技術的制約・非機能面の考慮事項

- 事務所の PC ブラウザ。
- 集計はサーバー（DB）で行う。日次は約 10 件、月次は約 250 件で、3 秒程度以内（NFR-001）。
- 印刷は A4 の印刷用ページ、CSV は BOM 付き UTF-8（E-04-S01、E-05-S01 と同じ方式）。
- **NFR-006 法令**：公表する項目と様式が卸売市場法と業務規程に合っているかは顧客が確認する（§10 #1）。
- **NFR-004**：出力は市場管理者だけ。出力操作を監査ログに残す。

## 9. 受入基準

- [ ] Given 指定日に品目 X の確定取引が 3 件（10 kg × 1,000 円、20 kg × 1,200 円、5 kg × 1,500 円）、When 日次の結果表を出す、Then 品目 X は数量 35 kg、高値 1,500 円、中値 1,200 円、安値 1,000 円、件数 3 と表示される。
- [ ] Given 承認待ち・却下・取消の取引、When 集計する、Then 結果表に含まれない。
- [ ] Given 相対取引とせりの両方がある品目、When 日次の結果表を出す、Then 合計と、相対取引・せりの内訳が表示される。
- [ ] Given 指定月、When 月次の結果表を出す、Then 品目ごとの数量・金額・平均単価が表示される。
- [ ] Given 結果表、When 印刷または CSV 出力する、Then A4 で崩れずに印刷でき、CSV は Excel で文字化けせずに開け、帳票に出力日時が印字される。
- [ ] Given 確定取引のない日、When 結果表を出す、Then 「対象の取引はありません。」と表示される。
- [ ] Given 卸売業者 担当者、When 画面を開く、または API を直接呼ぶ、Then 画面は表示されず、API は M_02 で拒否される。
- [ ] Given 結果表の出力、When 実行する、Then 出力者・日時・対象日が監査ログに残る。
